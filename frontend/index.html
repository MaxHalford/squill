No middleman

Your queries do not pass through us.

Squill has no application backend, user account, analytics service, or server-side credential store.

Canvases, settings, history, schemas, and cached results are stored by your browser. Google access tokens are short-lived and kept in memory only.

Questions, answered

No surprises

Do I need an account?

No. DuckDB works immediately. BigQuery uses your Google account only to authorize requests sent directly to Google.

Can Squill run queries by itself?

No. Queries run only when you press Run or use the keyboard shortcut, so nothing incurs cost unexpectedly.

Where is my work saved?

In browser storage on this device. Squill does not sync canvases to a server.

Is Squill open source?

Yes. The source is available on GitHub under the AGPL-3.0 license.
